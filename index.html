Installation

Alla appar finns som .deb (Ubuntu/Debian) och .rpm (Fedora) paket.

Ubuntu / Debian

echo "deb [signed-by=/usr/share/keyrings/yeager-keyring.gpg] https://yeager.github.io/debian-repo stable main" \
  | sudo tee /etc/apt/sources.list.d/yeager.list
curl -fsSL https://yeager.github.io/debian-repo/yeager-keyring.gpg \
  | sudo tee /usr/share/keyrings/yeager-keyring.gpg > /dev/null
sudo apt update

# Installera valfri app:
sudo apt install bildstod bildschema pecsbrada bildordbok rutinkompis tidskollen ordbyggaren

Fedora / openSUSE

sudo dnf config-manager --add-repo https://yeager.github.io/rpm-repo/yeager.repo

# Installera valfri app:
sudo dnf install bildstod bildschema pecsbrada bildordbok rutinkompis tidskollen ordbyggaren
