Offline-instruktioner

Alla appar fungerar offline efter första besöket!

✅ Hur fungerar det?

Autismappar är en PWA (Progressive Web App) med en service worker som sparar alla appar lokalt på din enhet. Efter första besöket kan du använda allt utan internet.

📱 Installera på din enhet

Du kan installera Autismappar som en app på hemskärmen — den ser ut och fungerar precis som en vanlig app!

🍎 iPhone / iPad

  1. Öppna Autismappar i Safari
  2. Tryck på Dela-knappen (rutan med pil uppåt) ⬆️
  3. Scrolla ner och tryck "Lägg till på hemskärmen" 📲
  4. Tryck "Lägg till" — klart! Appen finns nu på hemskärmen

🤖 Android

  1. Öppna Autismappar i Chrome
  2. Tryck på menyn (tre prickar ⋮) uppe till höger
  3. Tryck "Installera app" eller "Lägg till på startskärmen" 📲

💻 Dator (Chrome/Edge)

  1. Öppna Autismappar i Chrome eller Edge
  2. Klicka på installera-ikonen i adressfältet (ser ut som en dator med pil ⬇️)
  3. Klicka "Installera" — appen öppnas som ett eget fönster

🔄 Uppdatera appen

Appen uppdateras automatiskt när det finns en ny version. Stäng appen helt och öppna den igen. Den nya versionen laddas ner i bakgrunden vid nästa besök med internet.

🛠️ Felsökning

Om något inte fungerar som det ska, prova följande:

  • Stäng appen helt och öppna den igen
  • Rensa webbläsarens cache: Inställningar → Sekretess → Rensa webbdata
  • Ta bort appen från hemskärmen och installera den igen
